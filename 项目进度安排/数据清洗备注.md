# 数据清洗备注

这份备注只记录清洗后的目标形态，不放进待办事项。

## 主表

保留字段：
- id
- 中文名
- 英文/葡文名
- 区域
- 地址
- 开放时间
- 门票
- 经纬度

清洗要求：
- 统一列名
- 补齐经纬度
- 标准化开放时间
- 标准化门票文本

## 适老化表

保留字段：
- attraction_id
- 轮椅友善
- 电梯/扶梯
- 陡坡
- 台阶数
- 长椅/休息点
- 无障碍厕所
- 无障碍入口
- 坡道
- 扶手
- 路面状况
- 步行距离
- 建议停留时长
- 人流压力
- 噪音压力
- 暴晒/淋雨风险
- 室内/冷气休息点
- 推荐长者入口/路线
- 建议避开的路线
- 长者提示语

清洗要求：
- 删除网页抓取残留
- 统一布尔、等级、数值表达
- 统一未知值写法
- 长文本只保留可读内容

## 交通表

保留字段：
- attraction_id
- 交通类型
- 路线
- 低地板/轮椅座椅可用性
- 上车点
- 下车点
- 下车后步行指引

清洗要求：
- 拆分多线路信息
- 统一交通类型命名
- 把“是否低地板”整理成可判断字段
- 步行指引保留为可读文本

## 理由表

保留字段：
- id
- 景点名称
- 景点类别
- 区域
- 适老化推荐理由

清洗要求：
- 每个 id 只保留一条理由
- 理由控制为一句到两句
- 直接说明适合的人群和场景

## 接入 demo 的目标形态

- planner：按区域、疲劳、交通、停留时长筛选
- scorer：按适老性、交通便利、步行成本、餐饮/执行性评分
- executor：执行前检查是否适合该人群
- explainability：输出“为什么适合”
