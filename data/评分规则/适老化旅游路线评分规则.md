# 适老化旅游路线评价方法与评分规则（计划书版）

## 一、研究目标

本研究面向澳门适老化旅游路线推荐场景，拟构建一套基于老人旅游需求、无障碍旅游理论和文字资料统计编码方法的路线评价体系。该体系用于识别景点与路线在步行安全、交通可达、休息支持、信息可执行性和环境舒适度方面的适老化水平，并在后续实际使用中结合用户反馈持续修正评价结果。

本研究不采用研究者主观设定的固定权重，也不直接将文字描述简单换算为 0-100 分。考虑到现有数据表以文字描述、等级文本和“官方未说明/待核实”为主，本研究采用“文本证据编码 + 编码一致性检验 + 分维度潜变量估计 + 用户反馈校准”的方法，使评价过程具有可解释性、可复核性和后续迭代能力。

## 二、数据来源

本研究使用 `D:\personal\比赛\old people UM\outputs\update\excel` 目录下的澳门景点数据表，主要包括：

| `attraction_transport_updated.xlsx` | 提供交通方式、线路、上下车点、低地板/轮椅座位信息和下车后步行指引 |

|---|---|---|

| 体验舒适需求 | 老人旅游动机研究；环境压力理论 | 环境舒适度 |

## 四、评价维度设置

本研究设置 5 个一级评价维度。餐饮适配不作为核心一级维度，原因是澳门本地餐饮密度较高，茶餐厅及本地餐饮选择较多，同时现有数据表未系统采集餐饮字段。餐饮因素在本研究中作为路线备注和人工校验项处理。

| 维度代码 | 维度名称 | 评价内容 |
|---|---|---|
| D1 | 步行安全与体力负荷 | 距离、坡度、台阶、路面、防滑、绊倒风险、久站、人流、暴晒和休息点 |
| D2 | 景点与交通可达性 | 轮椅友好、电梯、无障碍入口、坡道、扶手、厕所、交通方式、线路、上下车点和下车后步行可达性 |
| D3 | 休息与生理支持 | 座椅/休息点、遮阴、室内/冷气休息、厕所便利、工作人员协助和急救支持 |
| D4 | 信息与执行可行性 | 开放时间、门票/长者优惠、推荐入口、避开路线、长者提示、交通指引和区域连贯性 |
| D5 | 环境舒适度 | 人流、噪音、暴晒/淋雨、遮阴/室内环境、路面舒适性和休息节奏 |

## 五、文本证据编码规则

由于原始表格主要为文字描述，本研究首先通过编码表将文字证据转化为有序分类变量。每个检查项统一编码为：

| 编码 | 含义 | 说明 |
|---:|---|---|
| 2 | 明确满足 | 文本明确显示该条件对长者友好或有明确支持 |
| 1 | 部分满足 / 信息有限 | 文本显示一般、局部支持、需留意，或存在轻微限制 |
| 0 | 明确不满足 / 有风险 | 文本明确显示障碍、风险或不适合 |
| NA | 无法判断 | 官方未说明、待核实、空值、`-1` 且无补充文本 |

其中，`NA` 不等于 `0`。官方未说明只能表示证据不足，不能直接判定为不适老。编码细则见配套文件 `适老化旅游路线编码表_codebook.xlsx`。

## 六、编码一致性检验

为了降低研究者个人判断对结果的影响，本研究采用双人独立编码机制。两名编码者依据同一份编码表分别对文字字段进行编码，在编码完成后计算一致性指标。

当编码者为两人，且编码值为有序类别 `0 < 1 < 2` 时，建议使用 Weighted Cohen's Kappa；当编码者为三人及以上，或缺失值较多时，建议使用 Krippendorff's Alpha。

| 一致性水平 | 处理方式 |
|---|---|
| ≥ 0.80 | 编码可靠，可进入后续统计评价 |
| 0.667-0.80 | 可用于探索性分析，但需在报告中说明限制 |
| < 0.667 | 编码规则不稳定，应修订编码表并重新编码 |

对不一致的编码项，应回查原始文本。若差异较小，可由编码者讨论确定；若差异较大，应由第三人复核或暂列为无法判断。

## 七、分维度得分估计

编码一致性达标后，将每个评价维度下的检查项视为一组有序分类题项。每个景点或路线节点为被评价对象，检查项编码结果为题项反应。

根据编码类型选择统计模型：

| 编码形式 | 推荐模型 | 适用场景 |
|---|---|---|
| 二分类 `0/1` | Rasch Model | 仅判断是否满足时使用 |
| 有序三分类 `0/1/2` | Partial Credit Model 或 Graded Response Model | 区分不满足、部分满足、明确满足时使用 |

模型输出为各景点在不同维度上的潜在适老化水平，记为：

| 输出字段 | 含义 |
|---|---|
| `theta_D1` | 步行安全与体力负荷潜在得分 |
| `theta_D2` | 景点与交通可达性潜在得分 |
| `theta_D3` | 休息与生理支持潜在得分 |
| `theta_D4` | 信息与执行可行性潜在得分 |
| `theta_D5` | 环境舒适度潜在得分 |

`theta` 值越高，表示该对象在对应维度上越适合长者。该得分不是研究者主观赋权，而是由同一维度下多个编码题项共同估计得到。

若当前样本量不足、题项缺失较多或模型无法稳定收敛，则不强行计算潜变量得分，仅报告编码结果、关键风险和证据完整度。

## 八、关键风险与路线短板机制

适老化路线具有明显短板效应。某一节点存在严重障碍时，不宜被其他优势简单抵消。因此除模型得分外，本研究设置关键风险标记。

关键风险包括但不限于：

| 维度 | 关键风险示例 |
|---|---|
| D1 步行安全与体力负荷 | 陡坡、明显石级、绊倒风险高、长距离且休息点少 |
| D2 景点与交通可达性 | 轮椅画像下 `wheelchair_friendly=false`；下车点待核实；步行指引建议行动不便者改乘的士 |
| D3 休息与生理支持 | 长停留路线中厕所不便或休息点少 |
| D4 信息与执行可行性 | 关键景点开放时间不明或与计划冲突；路线指引严重缺失 |
| D5 环境舒适度 | 高人流、高噪音、强暴晒且缺乏遮阴/休息点 |

路线层面建议采用以下聚合原则：

| 维度 | 路线聚合方式 | 理由 |
|---|---|---|
| D1 | 取最低值或下四分位值 | 一个高负荷节点可能导致整条路线失败 |
| D2 | 取最低值，并叠加交通关键风险 | 交通或入口任一断点会破坏可达链条 |
| D3 | 取均值，同时检查最长无休息时段 | 休息支持既有累积效应，也有短板风险 |
| D4 | 取最低值 | 一个关键景点时间/票务不明确会影响整条路线 |
| D5 | 取均值或下四分位值 | 舒适度可部分补偿，但高风险环境需提示 |

路线结论分为：

| 结论 | 判定逻辑 |
|---|---|
| 推荐 | 核心维度 D1/D2/D3 无关键风险，证据完整度较高 |
| 可推荐但需提示 | 存在轻中度风险，但可通过提醒、减少点位、调整顺序缓解 |
| 需人工复核 | 数据完整度不足，或多个维度存在风险但未触发明确不推荐 |
| 不推荐/需改线 | 触发核心维度关键风险，如陡坡石级严重、交通断点、轮椅不友好且目标人群行动不便 |

## 九、用户反馈校准机制

本研究设置实际使用反馈机制。用户反馈不是人工随意修改分数，而是作为外部结果变量，用于发现编码表漏项、修正关键风险规则，并在样本量充足后估计各维度对真实体验的影响。

### 9.1 反馈采集内容

每次路线使用后，建议记录路线完成情况、满意度、疲劳程度、步行困难、交通困难、如厕问题、休息不足、无障碍问题、信息不清和开放反馈。字段模板见配套文件 `适老化旅游用户反馈字段模板.xlsx`。

### 9.2 反馈使用方式

反馈分三层使用：

| 层级 | 用途 | 处理方式 |
|---|---|---|
| 第一层 | 发现编码表漏项 | 若用户多次反馈某类问题但编码表无对应题项，则新增或细化检查项 |
| 第二层 | 校准关键风险 | 若某类文本模式反复对应未完成、疲劳高或满意度低，则升级为关键风险 |
| 第三层 | 估计维度影响 | 当反馈样本充足后，用统计模型估计各维度对完成率和满意度的影响 |

可使用的反馈模型包括：

| 反馈结果 | 推荐模型 |
|---|---|
| 是否完成路线 `completed` | Logistic regression |
| 总体满意度 `overall_satisfaction` | Ordinal logistic regression |
| 疲劳程度 `fatigue_level` | Ordinal logistic regression |
| 是否发生具体问题 | Logistic regression |

示例模型：

```text
overall_satisfaction ~ theta_D1 + theta_D2 + theta_D3 + theta_D4 + theta_D5 + user_profile
completed ~ theta_D1 + theta_D2 + theta_D3 + theta_D4 + theta_D5 + user_profile
```

模型系数用于解释不同维度对真实用户体验的影响程度。只有在反馈样本达到一定规模后，才可用反馈模型进行稳定校准；在小样本阶段，仅将反馈用于人工复核和编码表修订。

## 十一、实施步骤

本研究计划按以下步骤执行：

1. 整理现有景点、无障碍、交通和门票数据，形成统一景点主键。
2. 依据老人旅游需求和理论框架确定评价维度。
3. 使用 `适老化旅游路线编码表_codebook.xlsx` 对文字字段进行编码。
4. 由至少两名编码者独立编码，并计算 Weighted Cohen's Kappa 或 Krippendorff's Alpha。
5. 对一致性不足的题项修订编码规则并重新编码。
6. 在编码一致性达标后，采用 Rasch、Partial Credit Model 或 Graded Response Model 估计各维度潜在得分。
7. 结合关键风险标记和路线短板原则形成路线推荐结论。
8. 上线后使用 `适老化旅游用户反馈字段模板.xlsx` 记录实际体验反馈。
9. 定期根据反馈修订编码表、关键风险规则和统计模型。

通过上述流程，评价体系能够从“理论驱动的初始规则”逐步转向“用户反馈校准的经验模型”，从而提高适老化路线推荐的可靠性和实际可用性。
